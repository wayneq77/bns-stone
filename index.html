機制說明 / Mechanism Explanation

[TW] 目前預設靈石為「不會被撿乾淨」。靈石出現 20 分鐘自然消失後，系統會倒數 140 分鐘，也就是在它消失後的 140 分鐘（2小時20分） 後才會再次出現。
如果靈石提前被撿乾淨，請務必點擊「已撿完」按鈕。點擊後系統會立即將下次出現時間設定為當下時間的 2 小時後。
微調按鈕： 卡片上的 +1 -1 +10 -10 是用來微調時間的。如果您晚了幾分鐘才設定，可以透過這些按鈕把時間倒退或往前推，讓倒數時間完全貼近真實的靈石出現時間！

[EN] By default, the system assumes stones are NOT fully collected. After a stone is active for 20 minutes and disappears naturally, the next spawn is set to 140 minutes after its disappearance.
If the stones are fully collected early, please click the "Collected" button. This instantly schedules the next spawn to exactly 2 hours from the current time.
Adjust Buttons: Use the +1 -1 +10 -10 buttons on the card to fine-tune the timer. If you set the spawn time a few minutes late, use these buttons to sync the countdown perfectly with the real spawn time.
