💎 靈石追蹤器

劍靈：革命 · 及時掌握靈石動向

離線 (本地模式)

機制說明 / Mechanism Explanation

🇹🇼 [TW] 繁體中文
  • 自然消失 (預設)：靈石出現 20 分鐘後自動消失，接著系統會倒數 140 分鐘（2小時20分）才會再次出現。
  • 手動點擊「已撿完」：若靈石提前被採集完畢，點擊按鈕後，下次出現時間將會強制設定為 當下時間的 120 分鐘後。
  • 時間微調 (+1, -1 等)：如果您晚了幾分鐘才設定，請使用這些按鈕將時間往前或往後推，讓倒數完美貼近真實時間。
🇬🇧 [EN] English
  • Auto Despawn (Default): Stones last for 20 minutes. After disappearing naturally, the next spawn is set to exactly 140 minutes later.
  • Manual "Collected": If stones are fully collected early, clicking this button instantly schedules the next spawn to 120 minutes from the current time.
  • Adjust Buttons (+1, -1, etc): If you set the timer late, use these to fine-tune the countdown to match the exact spawn time.
🇮🇩 [ID] Bahasa Indonesia
  • Menghilang Otomatis (Default): Batu bertahan 20 menit. Jika menghilang sendiri, sistem akan menghitung mundur 140 menit (2 jam 20 menit) untuk spawn berikutnya.
  • Tombol "Diambil Semua": Jika semua batu diambil lebih awal, tekan tombol ini untuk mengatur waktu spawn berikutnya menjadi tepat 120 menit dari sekarang.
  • Tombol Penyesuaian (+1, -1, dll): Jika Anda terlambat mengatur waktu, gunakan tombol ini untuk menyesuaikan hitungan mundur dengan waktu spawn yang sebenarnya.
